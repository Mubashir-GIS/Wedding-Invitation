SYSTEM SETTINGS

Connection & security

Guest data loads through the private server API after the Google Sheet and Vercel secrets are configured. The dashboard refreshes every 30 seconds.

Google Sheets connection

RSVP submissions will arrive from the website through the server-side Vercel API and be saved in the private wedding Google Sheet. The dashboard will load those records using an authenticated admin API.

Website → /api/rsvp → Google Apps Script → Google Sheets

Private admin access

This dashboard requires a private administrator password. Guest data is fetched from the Google Sheet only after the server validates the signed-in admin session.

Private URL: /admin/

Backend setup

  1. Open the wedding Google Sheet and create its Apps Script project.
  2. Paste the current backend/Code.gs, run setupRSVP once, and deploy it as a Web App.
  3. Set Vercel environment variables: Apps Script URL, shared secret, admin password (16+ characters), and session secret (32+ characters).
  4. Redeploy the preview and verify using a separate test sheet before sharing it with guests.

Data privacy

The guest list contains names, RSVP choices, invited plus-one names and messages. No email address or meal preference is requested. Guest data stays behind the private admin API; service secrets belong only in Vercel environment variables.
